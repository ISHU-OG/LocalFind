# LocalFind

Local shop discovery and in-person discount redemption (DECODEP HACKDAY 1.0).

Stack: React + TypeScript + Vite + Tailwind, Leaflet/OpenStreetMap, Firebase Auth + Firestore + Hosting.

**This is a work-in-progress migration from Supabase/device-ID identity to Firebase accounts.
See `STATUS.md` for exactly what is done and what remains.**
